Comment configurer JSONBin ?
  1. Crée un compte sur jsonbin.io (gratuit, 100k requêtes/mois).
  2. Dans le menu API Keys, copie la X-Master-Key (commence par $2a$10$).
  3. Crée un nouveau bin (n'importe quel JSON, ex: {}).
  4. Copie son Bin ID (24 caractères dans l'URL).
  5. Colle les deux ici, coche "Activer", clique "Enregistrer".
  6. Partage ces 2 valeurs avec ton équipe (chacun les saisit une fois sur son navigateur).

⚠️ RGPD : JSONBin héberge aux USA. Acceptable en MVP, à migrer vers un backend EU (Supabase EU, Cloudflare Worker) avant montée en charge.
